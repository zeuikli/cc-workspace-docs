## 全文

Workflows are the biggest upgrade to Claude Code's capabilities since skills and subagents.

I dove deep into it with @sidbid to figure out best practices, examples and more. I'm particularly excited about the non-technical tasks it enables for Claude Code.

Key findings after deep dive:

→ Workflows are NOT just for code. They're transformative for knowledge work: research synthesis, document analysis, content pipelines.

→ Best pattern: Haiku workers + Opus/Sonnet synthesizer. Keeps costs sane while scaling horizontally.

→ Scope binding is everything. "Audit my codebase" = expensive. "Audit the 20 files in /src/api" = precise and affordable.

→ The workflow JS file is the deliverable. Save it. Version it. Reuse it.

→ Non-technical workflows that now make sense: PR analysis across 50 files, competitor monitoring across 30 sources, customer feedback synthesis.
