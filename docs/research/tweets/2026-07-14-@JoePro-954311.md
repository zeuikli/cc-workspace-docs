Frontend Design Skill

Create distinctive, production grade frontend interfaces that feel authored by a strong human designer, not averaged from template patterns.

Success Criteria

Distinct visual identity with a clear narrative and signature element

Production grade functionality with complete states and responsive behavior

Accessibility by default with WCAG AA intent

Token driven design system rather than one off styling

Zero reliance on recognizable AI tropes

## 研究摘要

**TL;DR**：一份可直接套用的 Claude Skill 全文，透過「反 AI 樣板」硬規則（禁 Inter/紫漸層/圓角卡片組合）強制生成有作者感的前端 UI。

### 核心論點

- 核心策略是**否定清單優先**：先定義 Abomination Checklist（Inter+紫漸層+圓角卡片+通用 icon 等具體樣板）明確禁止，比正面描述「要好看」更能約束生成結果收斂到樣板。
- 要求先定 Design Tokens（CSS custom properties 一次列全，色彩/字體/間距/圓角陰影/動效）再進版面，強制 token-driven 而非 one-off styling。
- 每次生成必須包含一個「Signature Element」（功能性而非裝飾性的記憶點），並列出 8 種候選方向避免每次收斂到同一種。
- Production Requirements 涵蓋 a11y（語意 HTML/鍵盤操作/focus visible）、responsive（≥3 breakpoints、44px touch target）、performance（canvas/WebGL 需 reduced mode）與 8 種必備互動狀態（含 Error/Empty/Loading），把「像人做的」與「可上線」綁在同一份 spec。
- 內建 Final Quality Gate 自我檢查清單，任何一項未過即視為 invalid output，形成弱 self-verification 閉環（雖仍是模型自報，非確定性驗證）。

### 關鍵數據 / 工具

- 平台：Claude Skills（Customize > Skills > Create skill）
- 涵蓋 8 種 art direction 範例（Editorial/Neo-brutalist/Luxury/Retro-futurist/Organic/Punk-zine/Bauhaus/Psychedelic）
- Design Tokens 清單：33 個 CSS custom properties（color/typography/spacing/radius-shadow/motion 五類）
- 8 項必備互動狀態：Default/Hover/Active/Focus/Disabled/Loading/Error/Empty

### 批判性觀察

- Quality Gate 是模型自報（self-verification），非確定性檢查，仍可能 pattern-match 過關而非真正達標——與 workspace `unverified_success` 閘門精神相符，需視為輔助而非替代人工/確定性驗收。
- Abomination Checklist 具體點名的樣板（Inter/紫漸層/圓角卡片/通用 icon）反映特定時期 AI 生成 UI 的常見缺陷，具時效性，未來需隨生成模型演進更新黑名單內容。
- 作為 prompt/skill 範本高度可操作，直接可複製套用於本 workspace 若有前端專案，屬「靜態提示詞」型，符合 SKILL 整合類型。
