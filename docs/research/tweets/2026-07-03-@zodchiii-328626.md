## 全文摘要

**定位**：Fable 5 免費視窗（至 7/7）使用優化指南，含 CLAUDE.md routing 模板和大型任務 kickoff 模板。

### Fable 5 時間軸（背景）

- 2026-06-09：發布
- 2026-06-12：因越獄報告被美國出口管制令下架
- 2026-07-01：管制解除，重新上線

### 核心路由公式

> **Weeks by hand → Fable 5. Minutes by hand → Sonnet 5.**

### CLAUDE.md 路由片段（直接可用）

```markdown
## Model routing (through July 7)
Default: Sonnet 5 for everyday work.

Use Fable 5 only for heavy, high-payoff tasks:
- large migrations (framework, language, dependency)
- codebase-wide refactors across many files
- complex multi-step builds
- hard bugs in tangled code (race conditions, subtle state)

Rule of thumb: weeks-by-hand → Fable 5, minutes-by-hand → Sonnet 5.
Protect the Fable 5 window. Don't spend it on small edits.

Note: some security-adjacent requests get rerouted to Opus 4.8
by the new safeguards. If quality drops on one call, check for a reroute.
```

### 大型任務 Kickoff 模板（直接可用）

```markdown
# Task: [migration / refactor name]

## Goal
[One sentence: the end state you want.]

## Scope
- Files/dirs in scope: [paths]
- Out of scope: [paths to leave alone]

## Constraints
- Keep all tests passing.
- Preserve public APIs unless listed below.
- Match existing code style.

## Plan first
Before changing anything, map the full plan and list the files
you'll touch. Wait for my go-ahead, then execute in one pass.

## Definition of done
- [ ] [check 1]
- [ ] [check 2]
- [ ] all tests green
```

**關鍵語句**：「Plan first, then execute in one pass」是讓 Fable 5 真正發揮的關鍵。

### 新 Safeguards（回歸後新增）

- 新分類器針對一種特定越獄技術，攔截率 99%+
- 被攔截的請求 **自動 reroute 到 Opus 4.8**，並告知用戶
- 副作用：正常 coding/debugging 的誤判增加，安全相關工作可能被 reroute
- ⚠️ 30 天 prompt/output 保留政策（用於越獄研究）

### 常見錯誤

- 把 Fable 5 當聊天模型用（消耗免費額度）
- 錯過 7/7 截止日後的費用變化
- 未注意 safeguard reroute（品質驟降未察覺）
- 50% 額度分散在小任務上

## 研究摘要

**TL;DR**：Fable 5 使用優化指南：核心公式「weeks-by-hand → Fable 5」；CLAUDE.md routing 片段 + kickoff 模板可直接使用；safeguard rerouting 到 Opus 4.8 的機制說明；30 天資料保留政策確認（同 kirillk_web3）。

### 核心論點

- **路由決策公式**：工作量（以天/週衡量）而非任務類型決定模型選擇
- **Safeguard rerouting**：安全相關任務可能靜默降至 Opus 4.8，需主動確認模型
- **Plan first, execute once**：Fable 5 最有效的使用方式是先讓它規劃再一次執行

### 關鍵數據 / 工具

- 路由公式：weeks/hand → Fable, minutes/hand → Sonnet
- CLAUDE.md routing 模板（含 Fable 5 任務類型清單）

### 批判性觀察
