## 全文

New in Claude Code (research preview): dynamic workflows.

Claude writes an orchestration script on the fly, then spins up a large fleet of coordinated subagents in parallel to take on your most complex tasks.

Use the word "workflow" in a prompt to get started.

Or enable ultracode mode (/effort ultracode) for automatic workflow creation on complex tasks.

What this unlocks:
→ Migrations touching hundreds of files
→ Codebase-wide audits
→ Parallel test generation
→ Multi-agent research synthesis

The orchestration script is saved, so workflows are reusable.

Docs: claude.ai/code/workflows
