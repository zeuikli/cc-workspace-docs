## 核心摘要

> Anthropic Applied AI 工程師 Isabella He 親授如何將 Claude Managed Agents 從 demo 推進到 production，37 分鐘 hands-on workshop，示範搭建一個 incident response（site reliability）agent。

### 1. 演進脈絡

| 階段 | 時間 | 說明 |
|------|------|------|
| Messages API | 2023 | 純 tokens in/out，所有 agent primitives 自行實作 |
| Claude Code Tools | ~2024 | Sandboxed tool execution，讓工具在容器內安全運行 |
| Claude Managed Agents | 現在 | Purpose-built harness，production-ready，開發速度快 10–15× |

### 2. 核心架構：Brains（腦）與 Hands（手）分離

- **Brains（Server-side）**：agent definition、context management、compaction、prompt caching、observability console
- **Hands（Client-side）**：local tool execution，在用戶自己的基礎設施上執行，credentials 存在 Vaults 中

這個分離確保憑證安全性，開發者不需自建 secret store。

### 3. 五大 Primitives

1. **Agent Definition**：persona、capabilities、系統提示（server 端定義）
2. **Environments**：agent 可使用的 data、context、tool 清單
3. **Sessions**：Agent definition + Environment 組合，產生 conversation thread
4. **Local Tools**：`get_metrics`、`get_recent_deploys`、`get_diffs` 等，agent 在 session 中呼叫
5. **Streaming**：Sessions 以 **events** 為單位回傳（非 tokens in/out），支援即時串流 + observability logging

### 4. Sessions 以 Events 運作（關鍵差異）

傳統 Messages API 是 request/response（tokens in → tokens out）。  
Claude Managed Agents 中，一個 session 內所有互動都是 **events 追加到 log**：
- `user.message`、`agent.tool_call`、`agent.response` 等
- 每個 event 可即時 stream 給前端用戶
- 同時作為 observability 記錄，可在 console 查看 agent 完整行為

### 5. Context Anxiety 案例

Sonnet 4.5 出現「context anxiety」問題：context window 還有空間時就提前結束任務。  
團隊在 harness 中加入緩解機制 → 但 Opus 4.5 發布後此行為消失 → harness 中的修補變成廢棄代碼。  
**教訓**：harness 必須與模型一起演進，這是選擇 managed harness 的原因之一。

### 6. 進階功能（Beyond the Basics）

- **Dreaming**：self-improving agents + memory（下一個 session 主題）
- **Webhooks**：讓 agent 響應外部事件觸發
- **Fine-grained permission policies**：細粒度工具執行權限
- **MCP Server controls**：新發布的 MCP server 管理功能
- **Console Agent Builder**：Anthropic console 內建 observability dashboard + 視覺化 agent 定義介面
- **Credential Vaults**：built-in secret store，無需自建

### 7. Demo 重點

- Framework：Streamlit + Python
- Use case：Incident Response Agent（SRE agent）
- 工具：`get_metrics`、`get_recent_deploys`、`get_diffs`
- 流程：Clone repo → `.env` 填入 Anthropic API key → `streamlit run app.py`
- Agent 回應 3AM oncall 場景，自動分析 metrics、diff、deploy 記錄

**[07:00 → 07:10]** *(架構說明：Brains vs Hands)*
The agent itself, the brains, lives on Anthropic's servers. The hands of the agent, where tools actually get executed, live locally on your infrastructure or wherever you run your agent executor.

**[17:22 → 17:30]** *(Sessions 以 events 運作)*
When our Claude managed agents runs within a single session, instead of responding in tokens in and tokens out, it actually works in units of events. Events here are things like user messages or agent tool calls, agent responses, so that every event can be logged from an observability perspective as well as streamed back to the user.

**[27:18 → 27:57]** *(Workshop 總結)*
We started with an empty agent, built on a couple of primitives on Claude managed agents. We then defined the agent definition, the persona, the capabilities. We gave the agent an environment. We gave the agent data and context to operate over. We then gave the agent sessions combining the agent definitions to an environment so the agent can think through which tools to call. And then it can actually call those tools and take action on our behalf. We then came in and streamed the responses to the user into our logs, implemented some local tools as well as the ability to delete sessions.

**[35:24 → 35:42]** *(Credential Vaults)*
The brains and the hands of the agent are separated so that credentials can be stored very securely in these Vaults. This means that you don't have to set up your own secret stores or your own credential stores and you can just rely on the built-in capability here.

**[36:20 → 36:47]** *(結語)*
Hopefully everyone leaves here with a bit of a mental model about how managed agents actually works under the hood... you were able to come in and save future developers hours of time being woken up at 3 a.m. or 2 a.m. in the morning and being able to handle incidents for them.
