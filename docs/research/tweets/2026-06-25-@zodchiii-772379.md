## 全文

A senior Anthropic engineer just published the clearest blueprint on "How to give your AI agent a real memory" and it's a 15-page PDF.

Write → Consolidate → Recall → Apply

• Write: after every attempt, the agent records what it tried and what happened.

• Consolidate: it distills those raw attempts into a few reusable lessons, not a transcript dump.

• Recall: before the next task, it reads those lessons first.

• Apply: it skips the dead ends it already learned, even on a brand new problem.

The result is an agent that gets smarter per attempt—not just per fine-tune.

Why this matters: most people treat agent memory as retrieval (RAG). But retrieval without consolidation means the agent brings back noise, not signal. 

The real unlock is the Consolidate step: compression from "what happened" to "what to never do again."

Four memory types covered:
1. In-context (active working memory)
2. External store (files/DB)
3. In-weights (fine-tuning)
4. In-cache (KV cache reuse)

The 4-step loop is orthogonal to all four—it's the management layer on top.

Key insight: agents that write lessons after failure converge faster than agents that retry with the same context.
