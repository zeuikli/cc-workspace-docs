## 全文

An Anthropic senior dev just dropped an 11-page breakdown on "Loop Engineering."

The game has changed: you don't prompt the agent anymore, you build the system that prompts it.

The 5-step loop:

Discovery: The agent hunts down its own tasks (failing CIs/issues) instead of waiting for a list.

Handoff: Tasks run in isolated git worktrees so parallel agents don't clash.

Verification: A separate agent reviews the code assuming it's broken. (Rule #1: an agent grading its own work always gives it an A.)

Reporting: Code with no ticket = code that gets reverted. Every change gets a paper trail.

Continuous Improvement: The system watches its own failures and tunes the loop, not just the prompts.

The core thesis: A one-line prompt generates a one-line output. A system that contains its own feedback loop compounds.

This is the shift from vibe-coding to vibe-engineering.
