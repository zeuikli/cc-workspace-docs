Researchers tested two AI coding workflows that look identical:

Codex writes -> Claude reviews

## 研究摘要

**TL;DR**：同樣是「兩個模型互相審查」的架構，116 個高難度 coding 任務顯示 Claude 審查 Codex 大幅提升成績（71.6%→89.7%），但 Codex 審查 Claude 反而拉低成績（91.4%→82.8%）——角色分配比 agent 數量更重要。

### 核心論點

- 兩種表面相同的架構（A 寫 B 審 vs B 寫 A 審）實測結果不對稱：誰當 reviewer 決定結果好壞，不是「多一個 agent 審查」本身就會變好
- 反直覺結論：更強的模型當 writer、較弱模型當 reviewer 時，reviewer 可能拉低已經不錯的結果（91.4%→82.8%）
- 隱含推論：多 agent pipeline 設計時，writer/reviewer 角色分配需要根據模型能力差異調校，不能假設「加一層審查恆為正貢獻」

### 關鍵數據 / 工具

- 116 個高難度 coding 任務
- Codex 寫 → Claude 審：71.6% → 89.7%（+18.1pp）
- Claude 寫 → Codex 審：91.4% → 82.8%（-8.6pp）
