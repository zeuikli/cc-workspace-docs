## 全文

When Claude is working in a channel with four people, whose credentials does it use?

The answer: its own. When tagging Claude, Claude gets provisioned like any other teammate, with its own credentials.

We call this access model "agent identity". Here's how it works: 🧵

Agent identity means:
- Claude gets its own Slack credentials (not borrowing from any human)
- Provisioned automatically when tagged (like onboarding a new team member)
- Access is scoped to what Claude needs, not inherited from the human who tagged it
- Separation of credentials prevents privilege escalation via Claude

This is the new standard for how agents authenticate in collaborative environments. Instead of "which human's token should the agent borrow?", the question becomes "what identity does the agent have?"

Internal usage: Anthropic's own Claude Tag is used for 65% of product PRs that get merged, operating with this independent credential model.

Access model comparison:
- Old pattern: Agent uses human's OAuth token (risk: full human privileges)
- New pattern: Agent identity with scoped credentials (minimum necessary access)
