## 全文

Satya Nadella wrote about it. Google's Addy Osmani open sourced 23 skills around it. Anthropic is building infrastructure for it.

All in the last two weeks. Everyone is talking about loops in AI.

But nobody explained it simply. So I wrote the full breakdown.

Here is the short version:

→ Most people use AI one prompt at a time. You steer everything. That is the slow way.

→ A loop is when you build a small system that steers the AI for you. You give it a goal. It works, checks itself, fixes mistakes, tries again. You just watch.

→ The 4 pillars of a good loop:
1. The core while-loop (just 6 lines): task → model → action → check → repeat
2. Context: what the agent remembers between steps (task, past tries, current state)
3. Verification: who checks the work (separate evaluator, not the same agent)
4. Recovery: how the loop handles failures (retry, escalate, handoff)

→ Where competition happens: not the while-loop (anyone can write it) but context management, verification quality, and recovery strategies.

→ Satya, Addy, Anthropic all converging means: this is the emerging standard. Not a framework. A pattern.
