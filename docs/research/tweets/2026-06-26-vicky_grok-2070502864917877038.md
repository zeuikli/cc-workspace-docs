## 核心摘要

> 這是一堂以「調查鏡頭」系統梳理現代 LLM Transformer 架構演進的完整工作坊課程，涵蓋從 Vaswani 原始論文到 LLaMA、Gemma、Qwen 等當代模型的架構選擇、超參數設定與訓練穩定性技巧。

- 現代大語言模型架構共識已高度收斂：Pre-Norm（RMSNorm）+ RoPE 位置編碼 + SwiGLU 門控激活函數幾乎是所有主流模型的標配
- 超參數設計有清晰的經驗法則：FFN 維度為模型維度的 4 倍、注意力頭數與頭維度相等、模型深度/寬度比值約維持在 100 左右
- 訓練穩定性關鍵介入手段包括：QK Norm（控制 softmax 輸入規模）與 Logit Soft Capping（Gemma 系列）
- KV Cache 機制帶來推理效率問題，Group Query Attention（GQA）是目前最廣泛採用的平衡方案，在幾乎不損失表現力的前提下大幅降低記憶體存取成本
- 滑動視窗注意力（Sliding Window Attention）結合全局注意力的混合架構，是處理長上下文任務的主流趨勢

## 整理版（可讀逐字稿）

### 課程導言：為何用調查視角看架構（00:00–04:50）

講師以「架構過去一直很難懂」開場，提出這堂課的核心策略：與其枚舉所有設計選擇，不如系統性地審視大量已發布的現代語言模型（Qwen2、Nemotron 4、Gemma 4、Marin 等），從中歸納哪些選擇是「固定的」、哪些是「可以變動的」。最好的學習方式是自己動手訓練模型，而第二好的方式就是從他人的大量實驗中汲取共識。

### Transformer 基礎與架構變體（04:50–20:10）

從 Vaswani et al. 的原始 Transformer 出發，說明其標準選擇：正弦/餘弦位置編碼、ReLU 激活函數、Post-Norm 層歸一化。現代模型（尤其是 LLaMA 系列帶頭）轉向三個關鍵改變：**Pre-Norm**（將 LayerNorm 移到殘差塊前）、**RoPE**（旋轉位置嵌入）、以及 **SwiGLU**（門控線性單元）。講師指出 RMSNorm 幾乎取代了標準 LayerNorm，因其去除偏置項可提升算術密度，同時表現力不變。

### 門控線性單元（GLU）：SwiGLU 的原理（20:10–27:10）

詳細拆解 ReLU FFN 到 GLU 的演進。標準 ReLU 網路：`x → W1 → ReLU → W2 → output`；GLU 額外引入一個「門控」分支 V，以逐元素乘法調變 ReLU 的輸出。SwiGLU 用 Swish 函數取代 ReLU，是目前最主流的變體。由於引入第三個矩陣 V，FFN 隱藏維度需縮小為原來的 2/3 以維持相同參數量。講師評論這幾乎是「免費的性能提升」。

### Parallel Transformer Block 與架構實驗歷史（27:10–33:00）

介紹將注意力層與 MLP 層並行計算（而非串行）的架構變體，此想法源自 GPT-J，後被 PaLM 採用。並行化可共享層歸一化、融合矩陣乘法，帶來系統層面的優化空間。同期還介紹了多個 Google 在 2020 年代的架構實驗（Narang et al.），展現 Google 在架構上相較其他機構更願意大幅創新。

### RoPE 旋轉位置嵌入的數學原理（33:00–50:00）

深入講解 RoPE 的核心思想：位置嵌入應只依賴相對位置差，而非絕對位置。傳統方法（絕對位置嵌入、相對位置嵌入加在注意力矩陣上）皆無法完美實現此特性。RoPE 的解法：對語義詞向量按位置旋轉，利用「旋轉不改變內積」的幾何性質確保相對不變性。高維實作方式是將 d 維向量切成 d/2 個二維塊，每對維度以不同頻率旋轉（類似傅立葉分解），高頻捕捉局部位置、低頻捕捉長程位置。

### 超參數設計法則（50:00–01:05:00）

系統整理超參數設計的業界共識：FFN 維度 = 4 × 模型維度（「factor of 4」經驗法則）；注意力頭維度 = 模型維度 / 頭數，通常設為 64 或 128；模型的深度/寬度比（aspect ratio）約為 100。正則化方面，Dropout 在大規模預訓練中已基本廢棄（模型大、資料夠時自然正則化），但 weight decay 仍常用，且常與學習率聯動調整。

### 訓練穩定性：QK Norm 與 Logit Soft Capping（01:05:00–01:14:00）

訓練穩定性的主要威脅來自 softmax 的指數運算與除法——兩者皆容易數值爆炸。**QK Norm** 的做法是在計算 attention 前對 Q 和 K 各自做 RMSNorm，控制 softmax 輸入規模。此技術起源於多模態模型（edifix、Chameleon），後被廣泛移植至語言模型；幾乎不影響模型表現，但有效防止注意力退化。**Logit Soft Capping**（Gemma 2/3/4）則更激進：用 tanh 對 logit 硬性截頂，是比 QK Norm 更強的干預，但可能有輕微的表現損失。

### Group Query Attention（GQA）與推理效率（01:14:00–01:29:02）

解釋 KV Cache 機制為何在推理時造成記憶體頻寬瓶頸：每一步 decode 都要讀入完整的 KV 參數，導致算術密度下降。**MQA**（Multi-Query Attention）將所有頭共享同一組 K、V，大幅減少記憶體存取，但損失表現力。**GQA**（Group Query Attention）折中：K/V 頭數少於 Q 頭數，形成「每組 Q 頭共用一組 KV」的結構，在幾乎不損性能的前提下獲得顯著推理加速。今日幾乎所有主流模型都採用 GQA。最後介紹**滑動視窗注意力**（Sliding Window Attention，GPT-3 即有此概念），以及近期混合全局+局部注意力架構處理長上下文的趨勢，課程到此作結。
