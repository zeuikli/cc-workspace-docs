## 全文

This is a super exciting release - Claude Fable 5 is the same underlying model as Mythos but with added safeguards. The benchmarks are great and it's SOTA on everything by a margin but I'll add that *qualitatively* also, this is a major-version-bump-deserving step change forward (imo of the same order as Claude 4.5 was in November), peaking especially for long problem-solving sessions on very difficult problems. You can give it a lot more ambitious tasks than what you're used to, the model "gets it" more, requires less hand-holding and steering, and feels like working with a more senior engineer.

Free until June 22 (in Pro/Max plans, counts as ~2x Opus usage), then moves to usage credits. Highly recommend trying it before then if you haven't.
