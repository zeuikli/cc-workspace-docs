## 全文

Claude Fable 5 is here. New model generation, new way of working.

Here's how to get started in Claude Code and on the Claude Platform: 🧵

1/ In Claude Code: run `claude update` to get latest. Type `/model fable` to switch. Set `/effort` to `high` or `max` for complex tasks.

2/ Key differences from Opus 4.8:
- Can't disable thinking (set thinking:disabled → 400 error)
- Temperature parameter removed  
- Counts as ~2× Opus toward your usage plan

3/ Best first prompt: ask Fable to audit your CLAUDE.md and skills files for contradictions, stale rules, and patterns written for weaker models.

4/ The unit economics: Fable as orchestrator + Opus/Sonnet as workers = best performance-to-cost ratio for most workflows.

5/ Available in Claude Code, Cowork, and API (after June 22).
