## 全文摘要

When an AI agent fails in production, your observability tool shows you exactly what it did and almost nothing about how to fix it.

The real bottleneck isn't your observability. It's everything that has to happen after the trace lands on your screen.

**The four-layer stack:**

1. **Tracing**: `@opik.track` decorator, works with LangGraph, CrewAI, 50+ frameworks
2. **Ollie**: coding agent that reads span trees + source → proposes diff → user approves → reruns agent → locks regression test
3. **Test Suites**: plain-English assertions converted to LLM-as-a-judge checks; grows from real production failures
4. **Agent Sandbox**: run fully instrumented agent end-to-end in UI; non-developer stakeholders can test safely

**The loop**: Instrument → something fails → Ollie reads trace + source → proposes fix → approve → rerun in Sandbox → lock as regression test → repeat.

Every cycle, the harness gets harder to break.
