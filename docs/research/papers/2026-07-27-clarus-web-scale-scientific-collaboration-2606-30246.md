# Clarus: Coordinating Autonomous Research Agents toward Web-Scale Scientific Collaboration

## 摘要 / 核心貢獻
主張現有自主研究工具多為孤立助手而非真正協作平台，提出 Clarus 作為跨參與者（含人類研究者、團隊、實驗室、組織，非僅 AI）協調科研的基礎設施。以四層架構（Research Application／Digital Collaboration／Physical Substrate／Physical World）組織科研工作，目標使研究「開放、可稽核、可歸因、資源感知」，並建立「可溯源、可審查、可歸因、可累積」的協作網路信任機制。透過協作論文生成的案例研究驗證，展示 Clarus 如何把研究目標組織成跨多階段、多參與者的協調工作流。

## 為何屬「新領域」
「多參與者科研協作基礎設施」與 workspace 既有覆蓋（agent harness／單一委派拓撲）無語意重疊；核心關鍵詞 co-scientist（本文所涉概念族群）於既有覆蓋集合反向 grep 命中為 0。
