## Abstract

Retrieval-Augmented Generation (RAG) systems have recently shown remarkable advancements by integrating retrieval mechanisms into language models, enhancing their ability to produce more accurate and contextually relevant responses. However, the influence of various components and configurations within RAG systems remains underexplored. A comprehensive understanding of these elements is essential for tailoring RAG systems to complex retrieval tasks and ensuring optimal performance across diverse applications. In this paper, we develop several advanced RAG system designs that incorporate query expansion, various novel retrieval strategies, and a novel Contrastive In-Context Learning RAG. Our study systematically investigates key factors, including language model size, prompt design, document chunk size, knowledge base size, retrieval stride, query expansion techniques, Contrastive In-Context Learning knowledge bases, multilingual knowledge bases, and Focus Mode retrieving relevant context at sentence-level. Through extensive experimentation, we provide a detailed analysis of how these factors influence response quality. Our findings offer actionable insights for developing RAG systems, striking a balance between contextual richness and retrieval-generation efficiency, thereby paving the way for more adaptable and high-performing RAG frameworks in diverse real-world scenarios. Implementation code is made publicly accessible.

### 新型方法貢獻
**Contrastive In-Context Learning RAG**：在 in-context examples 中同時包含正確示範與對比性錯誤案例，引導模型更精確區分 relevant vs. irrelevant 資訊。

**Focus Mode**：從完整 document chunk 進一步提取句子級精確上下文，減少噪音、提升生成精確度，對應「contextual richness vs. retrieval-generation efficiency」的平衡。

**Query Expansion**：在檢索前擴充 query 表示，提升 recall；本文系統性比較多種 expansion 策略。

已知的量化結論：
- **Prompt 設計影響顯著**（RQ2）：細微的 prompt 變動可顯著影響 retrieval-generation 對齊度

## 對 Prompt Caching / Management / Engineering 的關聯

### Prompt Caching
- **Retrieval Stride 與快取互動**：較大的 retrieval stride（跳過更多段落）減少 prompt 長度，但可能降低召回；快取策略設計時應考慮 stride 對 prompt 長度穩定性的影響（stride 越大 -> prompt 越短 -> 快取前綴命中率越高）
- **Chunk Size 對快取 prefix 的影響**：Document chunk size 直接決定每次注入 context 的 token 量，進而影響是否超過 Anthropic 1,024 token 快取門檻；最佳 chunk size 應同時考慮 RAG 品質與快取可行性
- **Focus Mode 對快取的價值**：句子級 Focus Mode 縮短每次 context 長度 -> prompt 結構更穩定 -> prefix 快取命中率更高

### Prompt Management
- **System Prompt + Retrieval Context 邊界**：本文強調 prompt design（RQ2）對 RAG 對齊的重要性，prompt manager 應明確分離 system instruction（穩定，可快取）vs. retrieved context（動態，不快取）
- **Contrastive ICL 需要精心管理 few-shot examples**：正/負對比示範的 prompt 模板需版本控管，因為 examples 品質直接影響生成行為
- **多語言 KB 管理**（RQ8）：多語言配置引入 prompt 語言選擇問題——應在 system prompt 明確指定回應語言，避免模型根據 retrieved docs 語言決定輸出語言

### Prompt Engineering
- **Prompt Design 細節至關重要**（RQ2 主要發現）：即使語義等效的 prompt 措辭，對 RAG 的 retrieval-generation 對齊影響可能顯著，呼應 2601.22025 的核心論點（「更好」的通用 prompt 不一定更好）
- **Contrastive ICL 設計模式**：prompt engineer 可主動在 few-shot examples 中加入對比案例（「以下是錯誤做法」），明確引導模型邊界——這是可直接應用的 prompt 技巧
- **RAG prompt 設計黃金準則**：contextual richness（完整資訊）vs. retrieval-generation efficiency（token 精簡）的平衡，為 RAG prompt 設計提供可量化的優化方向
