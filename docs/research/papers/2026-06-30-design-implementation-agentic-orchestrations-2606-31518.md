# Design and Implementation of Agentic Orchestrations and Orchestration of Agents

## 摘要 / 核心貢獻
從企業流程管理（Business Process Management）角度切入，主張結合 AI 代理自主性與流程技術以兼顧健壯性、可追溯性；提出一套沿任務特定性、可追溯/可駕馭性、自主/反應性等屬性分類代理編排選項的框架，並提供決策準則與量測指標，透過預測性光感測情境驗證。

## 與 Harness 的關聯
該分類框架的「可追溯性/可駕馭性」維度與本 repo `core.md` 公理「不可逆不變式必須落 hook 或程式層」高度呼應——把編排選項按可駕馭程度分類，等同於為「哪些任務可交給 agent 自主判斷、哪些必須落確定性程序」提供外部學術佐證。
