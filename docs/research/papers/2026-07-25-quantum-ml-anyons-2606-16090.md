# Enhancing Quantum Machine Learning with Anyons

## 摘要 / 核心貢獻
本文提出統一量子核框架，涵蓋 bosonic、fermionic、anyonic 三種交換統計。透過表徵層分析（分數交換相位可存取對稱/反對稱極限無法觸及的特徵空間方向）、核幾何分析（分離度提升、複雜度降低）與基準測試三個角度，證明 anyonic 核在多個基準上優於其他核。作者將粒子交換統計定位為量子機器學習領域先前被忽視的一種運算資源。

## 為何屬「新領域」
以任意子（anyon）交換統計作為量子 ML 運算資源的理論框架，與 workspace 現有版圖無內容重疊；核心關鍵詞於三個既有集合反向 grep 命中皆為 0，與同批收錄的 2607.10563（議程）、2606.14822（工程）共同構成本次 quantum-classical-machine-learning 領域的理論層證據。
