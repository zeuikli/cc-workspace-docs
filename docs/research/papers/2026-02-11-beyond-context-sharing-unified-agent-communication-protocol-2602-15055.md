# Beyond Context Sharing: A Unified Agent Communication Protocol (ACP) for Secure, Federated, and Autonomous Agent-to-Agent (A2A) Orchestration

## 摘要 / 核心貢獻
提出 Agent Communication Protocol (ACP)，作為建構於 MCP 之上、面向跨異質環境的標準化 Agent-to-Agent 互動框架。結合去中心化身份驗證、語意意圖映射（semantic intent mapping）與自動化服務水準協議，主張在維持零信任安全模型的前提下降低跨代理通訊延遲，朝可互通的自主數位實體生態系邁進。

## 與 Harness 的關聯
「語意意圖映射」與「zero-trust 通訊延遲控制」呼應 `core.md §PROPOSE 委派`（原 `graph.md §G5`） 對外部/跨代理輸入的採信紀律——協定層面的身份驗證與意圖映射，可視為機械化落實「untrusted 導出的參數先確認」原則的一種基礎設施方案。
