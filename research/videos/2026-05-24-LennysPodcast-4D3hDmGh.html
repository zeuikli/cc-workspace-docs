The AI paradox: More automation, more humans, more work | Dan Shipper ​

來源: https://www.youtube.com/watch?v=4D3hDmGhFhA作者/頻道: Dan Shipper（Every CEO）/ Lenny's Podcast 發布日期: 2026-05-24 收錄日期: 2026-05-28 時長: 1:34:06 語言: 英文（自動字幕 en-orig）

核心摘要 ​

AI 越強人越忙的第一手親歷：自動化創造管理自動化的新工作，每個 Agent 都需要一個人照料。

三大預測框架 ​

Dan Shipper 從 Every（30 人全員 AI 重度使用公司，過去一年員工翻倍）的實戰經驗出發，提出三個層次的預測：

1. 工作方式的改變（How we work）

工作將沿兩條路徑同時演化：

路徑說明
公司共用 Agent（如 OpenClaw/Slack bot）整個公司共用一個 Agent，掛在 Slack，由專人（前沿部署工程師 FDE）維護
AI 成為工作 OS（Codex / Claude Code 環境）所有工作在 Codex/Claude Code 環境中進行，SaaS 工具作為子元件在 AI 環境裡跑

過渡路徑：OpenClaw 試驗 → 多數人放棄（需要 SSH、持續調整）→ 由 FDE 接手維護 → 穩定後再分散給個人。

2. 工作形態的改變（Shape of work）

「高級工程師基準測試」（Senior Engineer Benchmark）：Dan 用自己的出問題的 codebase 讓 AI 和人類重寫：

  • 一般模型：~30/100
  • GPT-5.5：62/100（唯一一個會主動說「這坨屎得重寫」的模型）
  • 人類高級工程師：85-90/100

差距核心：AI 能解決「被定義清楚的問題」，但無法主動判斷「這個問題需要被重新定義」。

工作型態轉型：

  • 非技術人員能做技術工作（PM、設計師可自己發 PR）
  • 技術人員轉為「確保非技術產出進得了 product」
  • 新角色「前沿部署工程師（FDE）」——源自 Palantir，負責維護公司 Agent 系統

3. 誰會最成功（Who succeeds）

  • PM（極度看好）：Marcus 案例——PM 背景，學了一年 Cursor，現在是 Every 出貨最快的人之一
  • 全端設計師（極度看好）：能自己發 PR、讓想法變成現實；vibe coding 氾濫後真正有美感的設計師更稀缺
  • BDR/Sales（面臨衝擊）：重複性最高的對外觸達工作
  • 「騎上模型（Ride the model）」：每次新模型出來，把它用在你真正在乎的問題上

其他反共識觀點 ​

  • CLI 時代已結束：Claude Code 的魔力不是 CLI 本身，而是本地完整訪問權限 + 大量訓練資料；GUI 是為了讓人舒服設計的，這邏輯沒變
  • SaaS 不會死：Agent 成為 SaaS 的新用戶，Every 的 SaaS 支出比去年還高；Dan 說他現在會買 SaaS 股票
  • AI 大規模失業不會發生：被歸因 AI 的裁員大多是過度招聘的修正，AI 只是藉口
  • AI 真正的前沿不在舊金山：在每一個把 AI 用在真實工作的人那裡；Every 在布魯克林，但他們比多數矽谷公司更靠近未來
  • GPT-5.5 目前領先：Dan 坦言目前主用 Codex（OpenAI），但強調會隨著最好用的工具切換，之前也大聲推過 Claude Code
